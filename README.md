# Balatro Reference

A reference repository for Balatro game code, mechanics, and development resources.

## Structure

- `/docs` - Documentation and guides
- `/code-snippets` - Code examples and snippets
- `/mechanics` - Game mechanics documentation
- `/resources` - External links and resources

## About Balatro

Balatro is a poker-themed roguelike deck-building game. This repository serves as a central place to collect and organize code references, mechanics documentation, and development resources related to Balatro.

## Usage

Browse the directories above to find specific references. Each directory contains organized information about different aspects of Balatro development and game mechanics.
